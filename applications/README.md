# Applications

One folder per job you apply for, named `YYYY-MM-company-role`. Create one with:

```bash
scripts/new-application.sh "Company" "Role"
```

Each folder holds:

| File | What it is |
|---|---|
| `job_description.md` | The posting, saved with its URL and date. Not built. |
| `resume.md` | The tailored resume. You edit this. |
| `cover_letter.md` | The cover letter. You edit this. |
| `*.txt`, `*.wd.txt`, `*.docx`, `*.pdf` | Generated by the build. Don't edit them; they get overwritten. `.wd.txt` is the Workday-friendly version of the resume. |

`_example-acme-platform-engineering-manager/` shows a finished example. Delete it once you've seen it.
